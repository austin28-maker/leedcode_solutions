## 解题思路

- 方法一：
    - 这题还有一种想法，而且扩展性很强，我做的字节的马里奥弹跳那题用的，这题相当于降阶题，就简单说下思想：
    - 建立一个存步数的数组step（数组值代表当前节点到终点所需最短步数） 从后往前遍历，
    - 当前节点走到终点需要的最短步数=如果能直接跳到终点则step[i] = 1;
    - 否则step[i] = min(step[i +1到Math.min(arr.length-1,i+arr[i])])的步数+1,
    - 也就是说当前节点到达中点的最小步数是他能跳到的所有节点最小步数的最小值+1，可以说是动规吧
    - 时间复杂度 O(n^2)（每个 i 都要扫一遍可跳区间取 min），会超时（代码以注释形式保留在 solution.java 中）

- 方法二（方法一的优化，正向贪心，O(n)）：
    - 优化观察：方法一的本质是"按步数分层"——step 值相同的位置构成一层，每多跳一步进入下一层
    - 由此不需要逐个取 min，只需从左到右维护两个变量：
        - curEnd：当前这一步能覆盖的最远边界（当前层的右端）
        - mx：遍历过程中不断用 i + nums[i] 更新的"下一步最远边界"（下一层的右端）
    - 遍历到 i == curEnd 时说明走完了当前层，必须再跳一步：ans++，新层右边界 curEnd = mx
    - 循环只需到 n-2 为止（站在终点上不需要再跳），也天然避免了终点处多计一步

- 贪心算法
    - 从左到右遍历，每次选择当前能跳到的最远位置，记录跳的次数

## 贪心正确性注记（区分两种"贪心"）

- 正确的贪心对象是"维护整层的最远边界"（mx），而不是"每一步真的跳到能跳的最远那个点"
    - 伪贪心（每步跳到单个最远点）：真的落地决策，会关死同层其他落点，可能翻车
    - 真贪心（分层边界）：mx 只是"下一步最远能到哪"的情报，不是落脚点，同层所有点都参与 max，不丢任何路径
- 区分两种策略的好标本：nums = [2,4,1,1,3]（真实最优 = 2 步：0→1→4）
    - 伪贪心：第 1 步跳到最远点 2（0+2）→ 第 2 步只能到 3 → 第 3 步到 4，共 3 步，错（落死在 2 号位，错过了旁边 nums=4 的宝地）
    - 真贪心：i=0 时 mx=2，ans=1；i=1 时 mx 冲到 5（nums[1]=4 的贡献被记下）；i=2 撞上边界 ans=2，curEnd=5，返回 2 步，对
- 贪心成立的直观解释："把边界推到最远"只是扩大信息，第 k 层的所有点都保留着，没有任何一条更优路径被关死；而找零钱反例（面额 [1,3,4] 凑 6：贪心 4+1+1 共 3 枚，最优 3+3 共 2 枚）翻车的原因正是"拿了 4 就关死了 3+3 这条路"
- 本题贪心成立的前提：题目保证一定可达（不可达的判断是 0055 的职责，本题贪心对不可达输入会数出假步数而不报错）

## 验证记录

- 临时测试桩验证 6 组用例全部通过：[2,3,1,1,4]→2、[2,3,0,1,4]→2、[1]→0、[1,2]→1、[1,1,1,1]→3、[3,1,1,1]→1
- 贪心正确性标本 [2,4,1,1,3]→2 亦验证通过（区分"跳最远点"伪贪心与"分层边界"真贪心）
