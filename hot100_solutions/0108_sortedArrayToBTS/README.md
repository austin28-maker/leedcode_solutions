## 思路

- 递归思想
- 每次递归将数组分为左右两部分，分别递归构建左子树和右子树。

## 知识点

- 二叉搜索树（BST）

BST 的核心性质 ：对任意节点， 左子树所有值 < 该节点值 < 右子树所有值

- 高度平衡二叉树

高度平衡二叉树是指任意节点的左右子树高度差不超过 1。

- 防止溢出

在递归过程中，需要确保数组的索引在有效范围内，避免溢出。

为什么不写 (left + right) / 2 ？因为可能溢出 ！（之前学过 int 溢出的问题）

left + (right - left) / 2 和 (left + right) / 2 结果相同，但前者不会溢出
