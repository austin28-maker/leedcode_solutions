## 注意事项

- 括号的生成要合法，即左括号“（”的数量不能大于右括号“）”的数量

- 本题区别于之前做的 0078 子集、0017 电话号码，之前的题目中`回溯`都是三步走：
    -   state.add(...);   // ① 做选择
        dfs(...);         // ② 递归
        state.remove(...);// ③ 撤销选择 
    -   本题最后一步的撤销选择在本题目中哪里体现呢？
        -   其实本题的`撤销`操作换了一种形式，即`覆盖`。
        -   在 dfs 中，我们直接`覆盖`了 path 数组中的字符，而不是添加到 state 中，所以不需要撤销选择。
    -   之前的题目为什么需要采用`撤销选择`的操作？
        -   因为`使用模式`不同，题目的本质要求不同。该题目生成的序列是固定长度的，而之前的题目结果长度是变化的。
        -   之前的题目中，使用的是ArrayList、StringBuilder 等追加操作，需要在递归结束后，撤销选择。
        -   而本题中，使用的是覆盖操作。所以不需要撤销选择。

- 递归的终止条件中
    -   当 right == n 时，说明已经填完了 2n 个括号，将当前的括号序列加入 ans 中。
    -   ans.add(new String(path));有两点需要注意：
        -   注意这里要 new String(path)，因为 path 在回溯的过程中会被修改。
        -   由于 path 是一个 char 数组，所以需要 new String(path) 将其转换为 String 类型。

- List<String>：元素类型为 String 的列表——列表里存的每个元素都是 String 对象的`引用`，而不是 String 对象本身。
