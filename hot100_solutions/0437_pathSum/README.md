## 解题思路

- 思路同0560_sub_arraySum
    - 都是利用前缀和思想
    - 都是利用哈希表存储前缀和的出现次数

- 不同之处在于，本题多了对树的遍历
    - 利用递归遍历树等价于数组的遍历

- dfs深度优先遍历树，每个节点只遍历一次，所以时间复杂度为O(n)

## 注意事项

- Long和Integer是包装类，属于对象，而long和int是基本类型

- int 是有符号类型，范围是 −2,147,483,648 到 2,147,483,647（约 ±2.1×10⁹），负数完全能表示。

- Java 里 int 和 Integer 从来不限于非负数。

- 为什么减1？
    - 这其实是回溯模式
    - 树有分叉。走左子树时登记的前缀和，属于"左路径"。
    - 回溯去走右子树时，左子树节点不在右路径上，它们的前缀和不该被右子树查到，
    - 否则会凑出一条"跨分支"的假路径（题目要求路径必须一直向下，不能跨分支）。
