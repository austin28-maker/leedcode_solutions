## 思路

- 做链表或者二叉树的题目时，先考虑节点是否为空
    - 如果节点为空，直接返回
    - 如果节点只有一个，直接返回
    - 如果节点大于等于2个，继续处理

## 知识点

- 归并排序是指将一个无序的序列，通过归并操作，将其有序化
- 链表找中间节点
- 链表合并两个有序链表
- 递归调用
    - 递归调用的条件是节点为空或者只有一个节点
    - 递归调用的逻辑是将链表分成两个部分，分别递归调用，最后合并两个有序链表

## 注意事项
- 递归调用时，要注意递归调用的范围是左开右闭区间，不包含tail
    - 所以head.next == tail时，说明head是最后一个节点
    - 所以head.next = null，将head从链表中分离出来
