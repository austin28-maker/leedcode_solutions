## 注意事项

- 区分子串和子集的区别
    -   子集：不连续的元素，可以是任意顺序
    -   子串：连续的元素，必须是顺序，并且所有子串合并成原本的字符串
        -   所以本题的思路就是把字符串 s 切成若干段，使每一段都是回文串，返回所有切法
        -   注意是"分割"不是"子序列"——切完后的段按顺序拼起来必须还原成原串，每个字符的位置都不能变

- 注意传参顺序不要错误

## 疑问澄清：为什么"不分割"分支不需要判断回文串？

- 曾经的疑惑：切与不切两种情况，是不是都要先判断回文串？"不分割"是不是应该放到回文判断的里面？
- 澄清后的结论：**回文检查是"切"的入场券，不是"不切"的入场券**
    - 切 = 段定稿：[start, i] 从"正在生长的半成品"变成"正式的一段"，正式的段必须是回文 → 切之前必须检查
    - 不切 = 段还在生长：没有定稿任何段，只是把"下刀决定"推迟到下一刀 → 无需检查，段变长后可能成为回文
- 两个 if 是**并列关系**而非嵌套关系，当 [start, i] 是回文时两个分支都会走：
    - 情况 1：提取当前回文串，对剩下的子串递归分析
    - 情况 2：不提取当前回文串，继续延长——当前子串加上后面的字符可能形成更长的回文串
- 如果把"不切"嵌套进回文判断里会漏解（反例 s = "abab"，start=0）：
    - 段 "ab"（i=1）不是回文 → "不切"被拦住 → 段无法继续延长
    - 段 "aba"（i=2）是回文 → 但延长路径已被拦截，该方案被**漏掉**
    - 正确写法："ab" 不是回文只是不能**切**，不切（延长）照走 → 长到 "aba" 回文成立 → 切
- 决策矩阵

    | [start, i] 是回文？ | 分支①不切 | 分支②切 |
    |--------------------|-----------|---------|
    | 是 | 走（可能凑成更长的回文） | 走（提取它，分析剩余部分） |
    | 不是 | 走（寄希望于变长后成回文） | 不走（切了也白切，剪枝） |
