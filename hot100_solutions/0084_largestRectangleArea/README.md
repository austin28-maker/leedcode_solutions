## 解题思路

- 使用单调栈
    - 遍历每个高度，以当前高度为基准，寻找`最大的宽度`组成最大的矩形面积
    - 就是要找`左边第一个`小于当前高度的下标left，
    - 再找`右边第一个`小于当前高度的下标right
    - 宽度就是这两个下标之间的距离，但是要排除这两个下标，所以是`right-left-1`
    - 用单调栈就可以很方便确定这两个边界了

## 知识点

- 单调栈
- 哨兵
    - 用于处理边界情况，避免额外的判断
    - 例如，在数组首尾各添加一个0高度，就可以避免在循环里判断栈是否为空
- 数组复制
    - System.arraycopy(源数组，源数组的起始位置，目标数组，目标数组的起始位置，复制的元素个数)
    - 例如，复制`heights`数组到`newHeights`数组的中间部分，就是`System.arraycopy(heights, 0, newHeights, 1, len);`
- 栈
    - 用于存储高度的下标，方便快速查找左右第一个小于当前高度的下标
    - .peekLast() 方法用于查看栈顶元素，不弹出
    - .pollLast() 方法用于弹出栈顶元素

## 注意事项

- 注意，这里要入栈的是`当前高度的下标`，而不是当前高度本身
    - 这是因为要计算宽度时，要排除这两个下标，所以要减1
    - 例如，当前高度是5，左边第一个小于5的高度是3，右边第一个小于5的高度是2，那么宽度就是`2-3-1=1`

- 计算当前高度时，不要忘记将左侧第一个比当前高度小的高度下标弹出栈，否则会导致宽度计算错误
