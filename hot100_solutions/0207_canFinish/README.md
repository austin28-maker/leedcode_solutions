## 知识点

- List和int[]的区别
  - List 是一个动态数组，int[] 是一个静态数组
  - List 可以在运行时动态添加或删除元素，int[] 不能在运行时动态添加或删除元素
  - List 可以在运行时动态调整大小，int[] 不能在运行时动态调整大小
  - List 可以在运行时动态调整元素的类型，int[] 不能在运行时动态调整元素的类型

- 理解从初始化一个`空列表`到正常调用`列表方法`过程
    - 最开始的声明：`List<List<Integer>> adjList = new ArrayList<>();`只是提出框架概念，里面连元素都没有
    - 然后再调用`adjList.add(new ArrayList<>());`，给每个元素添加一个空的 ArrayList，相当于adjList = [ [], [], [], ... ]
    - 最后可以正常调用方法`adjList.get(preCourse).add(course);`，将当前课程添加到前修课程的后续课程列表中

- 经典技巧：while 循环的使用配合队列queue非空条件
    - 当队列queue不为空时，继续执行循环体
    - 循环体中，从队列queue取出一个元素，进行处理
    - 处理完成后，将处理结果添加到队列queue中
    - 循环继续执行，直到队列queue为空

- 队列queue的含义和应用条件
    - 队列queue是一个先进先出的数据结构
    - 队列queue的offer方法是将元素添加到队列的末尾
    - 队列queue的poll方法是从队列的开头取出一个元素
    - 队列queue的isEmpty方法是判断队列是否为空
    - 队列queue的size方法是返回队列的元素数量
