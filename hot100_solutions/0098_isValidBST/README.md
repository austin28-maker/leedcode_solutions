## 知识点

- 二叉搜索树（BST）
对 每个节点，必须满足：
左子树所有节点值 < 当前节点值
右子树所有节点值 > 当前节点值
BST 要求的不是"父子关系"，而是"整棵子树的关系" 。右子树里的 每一个 节点都必须大于根节点。

## 思路

- 上下界法
- 递归检查左右子树是否符合 BST 定义


## 二编

- 前序遍历
    - 先访问根节点，再递归访问左子树，最后递归访问右子树
    - 递归检查左右子树是否符合 BST 定义
    - 每个节点的下界是其左子树的最大值，上界是其右子树的最小值
    - 注意理解根节点的上下界是 Long.MIN_VALUE 和 Long.MAX_VALUE

- 注意Long类型，避免整数溢出
    - 递归检查左右子树时，需要将当前节点的值作为下界，将当前节点的值作为上界
    - 注意：Python 中的 float 类型可以表示任意大的整数，所以不需要担心溢出问题
