## 思路

- 从所有腐烂的橘子开始，每次将所有相邻的橘子都腐烂。
- 直到没有新鲜的橘子为止。

## 知识点

- 广度优先搜索（BFS）
- 队列（Queue）的基本操作：
    - `offer()`：将元素添加到队列的末尾
    - `poll()`：从队列的开头移除元素
    - `peek()`：返回队列的开头元素
    - `isEmpty()`：判断队列是否为空

## 注意事项

- 思考同一批次的腐败橘子的遍历问题
- count的声明位置要放在 for 循环遍历之前
- 边界条件的处理，要避免越界，范围是 [0, M-1] 和 [0, N-1]

## 二编

- 思路该怎么展开？
    - 要求腐烂的橘子传播同一批次要统计好，ans表示传播的次数
    - 对于该批次被传染的烂橘子，就不用再回头去遍历传染源了

- 核心点在于统计好同批次腐烂的橘子，作为下一批次的传染源
- 用while循环来计算传播次数ans
