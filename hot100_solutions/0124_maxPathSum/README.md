## 解题思路

- 递归思想：
    - 递归函数的定义：
        - 递归函数的参数：当前节点
        - 递归函数的返回值：当前节点的最大链和
    - 递归函数的出口：当前节点为空时，返回0
    - 递归函数的递归过程：
        - 递归计算左子树的最大链和
        - 递归计算右子树的最大链和
        - 统计当前节点的最大路径和
        - 返回当前节点的最大链和

## 注意事项

- 区分路径和链
    - 路径：可以包含根节点，也可以不包含根节点，可以从下到上
    - 链：只能从上到下，不能从下到上
    - 本题目是将路径和转换为链和，因为路径和可以也可以不包含根节点，而链和只能从上到下，不能从下到上

- 如果所有节点的值都为负数，那么最大路径和就是最大的那个节点的值
    - 虽然最后dfs返回的是和0比大小的结果，但是ans是全局的，所以可以包含负数

- 主函数的返回值是ans
    - ans  一直是更新的最大值，并不是逐层增加的值，是比较出来的最大值

- 关于dfs递归函数返回值的理解：
    - dfs函数本质上就去计算当前节点的左右子树的最大链和
    - 当前节点的最大路径和就是左右子树的最大链和加上当前节点的值
    - 但是其中有2个需要计算考虑的数值，一个是统计的当前最大路径和，另一个是递归返回的值
