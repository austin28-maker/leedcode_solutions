## 解题思路

- 动态规划
    - 状态定义：dp[i] 表示以s[i]结尾的最长有效括号的长度
    - 状态转移：
        - 如果s[i] == ')'
            - 如果s[i - 1] == '('
                - dp[i] = dp[i - 2] + 2
            - 如果s[i - 1] == ')'
                - dp[i] = dp[i - 1] + 2 + dp[i - dp[i - 1] - 2]

## 注意事项

- 注意理解dp[i]的含义
- 计算dp[i]时，注意边界条件和状态转移的条件
