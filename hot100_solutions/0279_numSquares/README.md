## 解题思路

- 动态规划
    - dp[i]：凑出和为 i 所需完全平方数的最小个数
    - 初始状态 dp[i] = i，即最差保底方案：全用 1（1+1+...+1，共 i 个 1）；dp[0] = 0（凑 0 需要 0 个数）
    - 转移方程：dp[i] = min(dp[i], dp[i - j*j] + 1)
    - 其中 j 是底数（普通整数），j*j 才是完全平方数；j 枚举 1~k，k 为满足 k*k <= i 的最大底数
    - 含义：枚举"最后一枚放哪个完全平方数 j*j"，拿走它后剩下 i - j*j，
    - 所以 凑出 i 的最小个数 = 凑出 i-j*j 的最小个数 + 1（这 1 就是最后那枚 j*j）
    - 即 dp[i] = min over j of (dp[i - j*j] + 1)，与保底值 i 取更小者
    - 注：dp[j*j] 恒等于 1，因为 j*j 本身就是一个完全平方数，一个数即凑成
