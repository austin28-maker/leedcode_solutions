## 思路

顺时针的遍历，需要定义四个边界，分别表示矩阵的上、下、左、右边界。
遍历完其中一个边界后，需要更新该边界，将下一个元素加入到结果列表中。

为什么会用到ArrayList？
因为题目要求返回的结果是一个List，而ArrayList是一个实现List接口的类。
所以，我们需要将结果加入到ArrayList中，而不是直接返回一个数组。

使用 List（如 ArrayList）时，你可以直接调用 add() 方法将元素追加到末尾，无需关心底层容量的管理。
如果使用 int[]，你需要提前计算结果的总长度（即矩阵的行数乘列数 m * n），
并在遍历过程中维护一个额外的索引变量（如 index）来记录当前元素存放的位置。
使用 List 则省去了手动维护索引的麻烦。
