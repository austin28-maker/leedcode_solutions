## 解题思路

- 方法一：动态规划
  - 定义状态：dp[i] 表示以 nums[i] 结尾的最长递增子序列的长度
  - 状态转移方程：dp[i] = max(dp[j] + 1, dp[i]) ，其中 j < i 且 nums[j] < nums[i]
  - 初始化：dp[i] = 1
  - 结果：max(dp[i])

- 子序列：是指在原序列中不改变元素顺序的情况下，删除一些元素或不删除任何元素而得到的新序列。

## 二编

- 方法二：动态规划 + 二分查找
  - 核心操作就是插入操作：
  - 插入操作在这里是表示将当前数替换掉 dp 数组中第一个大于等于当前数的数。
  - 这样可以保持 dp 数组的递增性，同时更新最长递增子序列的长度。
  - 换句话说，可以保证这个队列始终是最长的递增子序列中元素最小的那种队列。方便后续的长度扩展。
  - 归根到底是为了优化时间复杂度。
    - 优化时间复杂度的关键在于如何快速找到 dp 数组中第一个大于等于当前数的数。
    - 这里可以使用二分查找来实现。
    - 二分查找的时间复杂度为 O(log n)，总的时间复杂度为 O(n log n)。
    - 这比方法一的时间复杂度 O(n^2) 要好得多。

- 注意二分查找的应用
  - 边界条件：left <= right
  - 最后返回left，因为left指向的是第一个大于等于当前数的数的索引。
  - 所以，dp[left] = nums[i]，就可以保持dp数组的递增性，同时更新最长递增子序列的长度。

- 注意理解二分查找时，if dp[mid] >= nums[i]这个条件的含义
  - 表示dp数组中第一个大于等于当前数的数的索引是mid
  - 所以，dp[left] = nums[i]，就可以保持dp数组的递增性，同时更新最长递增子序列的长度。

## 三编

- 最开始的想法是：
  - dp[i]表示以nums[i]结尾的递增子序列长度

- 但是要用到时间复杂度为nlogn，说明必须要采用二分查找，
  - 二分查找需要在一个有序环境中应用
    - 要么对原数组进行排序，
    - 要么对动态规划的数组进行排序

- 如果对原数组进行排序的话不满足子序列的概念，无法保证相对顺序。所以只能对动态规划的数组进行排序。
- 进一步就要求对动态规划数组含义的设计
- 此处dp[i]表示长度为i + 1的递增子序列的最小末尾元素。
  - 注意这个“最小”，这就是保证dp[i]数组有序的关键。

- 二分查找的应用就是在dp[i]上查找遍历到的当前元素对应的位置。
  - 注意二分查找的左右指针定义，右指针right = len - 1，len表示当前遍历时的最长递增子序列

- len何时进行更新呢？想想将遍历到的元素添加进dp数组时的操作：dp[left] = num
