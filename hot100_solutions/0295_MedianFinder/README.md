## 解题思路

- 堆（Heap）是一种优先级队列，它的出队顺序与插入顺序无关，而是与元素的大小（优先级）有关。
- 而队列（Queue）是一种先进先出的结构，它的出队顺序与插入顺序相同。
- Queue是一种FIFO（First In First Out）的结构，用于存储和管理元素。

- 使用两个堆，一个大顶堆，一个小顶堆，
- 其中大顶堆保存较小的一半，小顶堆保存较大的一半。

## 知识点

- 默认构造器 new PriorityQueue<>() 默认是小顶堆，
- 而大顶堆需要自定义比较器 comparator。
- PriorityQueue 并不是在任意时刻都保证“队列里所有元素完全按升序/降序排好”，
    - 而是保证堆顶（即 peek() 或 poll() 返回的元素）一定是极值（最小或最大）。
- 实际起排序作用的是你在调用 add()（入队） 和 poll()（出队） 这两个方法时，内部自动执行的 “堆化”算法（上浮与下沉）。
- 声明只是告诉它“用哪个规则来比较”，而不是“怎么比较”。
- PriorityQueue 只保证“堆顶有序”，不保证“全数组有序”。
- 如果你直接用 System.out.println(A) 打印这个队列，看到的内部数组顺序可能看起来是乱序的。
- 只有连续不断地调用 poll()，拿出来的元素才会呈现全局的升序/降序。
- 因为堆的内部存储是一个完全二叉树，只有根节点是极值。
