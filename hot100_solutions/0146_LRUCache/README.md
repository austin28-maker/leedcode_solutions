## 知识点

- LinkedHashMap
- 红黑树定义：
    - 每个节点都有一个颜色，要么是黑色，要么是红色
    - 根节点是黑色
    - 每个叶子节点（null节点）都是黑色
    - 每个红色节点的两个子节点都是黑色
    - 每个节点的每个路径上，从该节点到该路径的叶子节点的黑色节点数都是相等的
- 双向链表定义：
    - 每个节点都有一个前驱节点和后继节点
    - 前驱节点和后继节点都是指针，指向相邻的节点

## 注意事项

- 建议查看LinkedHashMap的源码，理解其工作原理
- 注意LinkedHashMap的get方法会更新链表顺序，而put方法不会更新
- 所以在实现LRUCache时，需要根据题目要求选择不同的方法
