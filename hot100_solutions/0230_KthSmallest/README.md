## 知识点
注意是二叉搜索树，不是二叉树
- 二叉搜索树
    - 左子树的节点值小于根节点值
    - 右子树的节点值大于根节点值
    - 左子树和右子树都是二叉搜索树

- 中序遍历
    - 左子树先遍历，再遍历根节点，最后遍历右子树
    - 中序遍历的结果是一个有序的序列

- 递归调用
    - 递归调用的条件是节点为空或者只有一个节点
    - 递归调用的逻辑是将二叉搜索树分成两个部分，分别递归调用，最后返回第k小的节点

## 语法知识

- 栈
    - 栈是一种先进后出的数据结构
    - 栈的实现可以使用数组或者链表

- Deque
    - Deque是一种双端队列，即可以在队头和队尾进行插入和删除操作
    - Deque的实现可以使用数组或者链表
