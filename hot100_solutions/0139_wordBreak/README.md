## 解题思路

- 动态规划
- 记忆化搜索
- 要学会找子问题。对于简单 DP 来说，想清楚【最后一步】发生了什么，也就想清楚了每一步发生了什么。
- 对于本题，最后一步就是把 wordDict 中的一个单词拼在了字符串的末尾，得到了 s。
- 倒推，从 s 的末尾去掉 wordDict 中的一个单词，可以得到一个更短的字符串（规模更小的子问题），
- 这样就知道递归怎么写了，然后就是记忆化搜索 -> 递推的过程了。

## 知识点

- HashSet
- substring 方法
    - 从字符串的指定索引开始，返回一个新字符串，该字符串包含从指定索引开始的字符。
    - 语法：`substring(int beginIndex)`
    - 语法：`substring(int beginIndex, int endIndex)`
    - 注意：`endIndex` 不包含在返回的字符串中。
    - 例如：`substring(2, 5)` 返回 "cde"，因为索引 2 开始，索引 5 结束，不包含索引 5 处的字符。
    - 例如：`substring(2)` 返回 "cde"，因为从索引 2 开始，直到字符串结束。

## 二编

- 注意if的条件，共有两条：
    - `f[j]` 表示 s 的前 j 个字符是否可以被 wordDict 中的单词拼成。
    - `s[j:i]` 表示 s 的第 j 个字符到第 i 个字符（不包含第 i 个字符）是否在 wordDict 中。

- 这里的break是跳出内层循环，继续外层循环，检查下一个i。
    - 这样就可以避免重复计算，提高效率。
