## 思路

滑窗双指针
法一：哈希表
法二：数组模拟哈希表
法三：逐个检查，先设置各字符的出现次数数组（注意理解实现的逻辑）

## 知识点

- 不要忘记先将字符串转换为字符数组
    转换的语法知识为：`char[] chars = s.toCharArray();`
    其中，`s`为字符串变量，`chars`为字符数组变量

- 求解字符串的长度用length()方法
    语法知识为：`int length = s.length();`
    其中，`s`为字符串变量，`length`为字符串长度变量

- 若求解数组的长度，直接用数组名.length即可
    语法知识为：`int length = chars.length;`
    其中，`chars`为字符数组变量，`length`为字符数组长度变量

- char 可以直接当数组下标，下标 c 就是字符 c 的 ASCII 码值
    语法知识为：`arr[c] = i + 1;`
    其中，`arr`为整数数组变量，`c`为字符变量，`i`为整数变量
    Java 里 char 本质上就是个 0~65535 的整数（它的 Unicode 码值）

## 巧妙之处

- new int[128] 创建时，所有格子默认是 0。但"0"在这里有歧义：
    它可能表示"这个字符还没出现过"
    但也可能被误解成"出现在第 0 位"
    所以代码里做了个巧妙设计（第 14 行）：存位置时用 arr[c] = i + 1（位置加 1），判断时用 arr[c] != 0 表示"出现过"。
    这样 0 就专门留给"没出现过"，不会和真实位置混淆。这个 +1 就是 line 14 那行的由来。
