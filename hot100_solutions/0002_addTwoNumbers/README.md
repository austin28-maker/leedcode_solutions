## 疑问

1 ListNode 只是"一个节点" ，不是整个链表
- ListNode 是 节点的类型 （一个盒子，里面有 val 和 next）
- l1 是一个 变量 ，它保存的是 第一个节点的地址 （指向头节点）
- 整条链表是通过每个节点的 next 一个一个串起来的， 没有一个变量能代表"整条链表"

2 游标节点
- 游标节点 是 一个 变量 ，它保存的是 当前节点的地址 （指向当前节点）
- 游标节点 用于 遍历链表 ，从头节点开始，一次指向下一个节点
- 游标节点 用于 连接新节点 ，将新节点连接到当前节点的 next 上
- 解答过程中的
    cursor.next = sumNode;
    cursor = sumNode;
    表示的其实就是如何将当前节点的索引指向下一个节点，并且下一个节点已经做出来修改，即新节点 sumNode
    所以，这里需要更新当前游标节点的下一节点为 sumNode 节点
    再更新游标节点，将它指向 sumNode 节点
    如此一来，当前游标节点就指向了新添加的节点 sumNode

3 为什么最后 return root.next 而不是 root？
- 因为 root 节点是 Head节点，它没有值，只是指向第一个节点
- 所以，最后返回 root.next 就是返回第一个节点
- 而不是返回 root 就是返回 Head节点
