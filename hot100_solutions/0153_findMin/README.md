## 思路

- 二分查找
- 旋转排序数组：利用中间元素与最后一个元素的关系，判断旋转点在左侧还是右侧。

## 注意事项

- 开区间 (-1, n-1)
- 闭区间 [0, n-1]
    - 闭区间的写法中，二分查找的循环体内必须 nums[mid] <= nums[n - 1] ，否则会越界
    - 任何最小值恰好是最后一个元素的输入（例如单元素数组）都会导致 left 指向最后一个元素，从而判断越界
- 开闭区间的理解

# 二编

- 二分查找的闭区间写法和开区间写法的区别
    - while (left <= right)是闭区间，while (left < right)是开区间
    - 闭区间的mid已经做过一次判断，而开区间的mid还没有做过判断
    - 闭区间的mid可能会指向最后一个元素，而开区间的mid不会指向最后一个元素
    - 所以闭区间的left和right指针需要对mid做+1和-1操作，而开区间的left和right指针不需要做任何操作

- 注意闭区间是[0, n-2]，因为left会进行mid + 1的操作，指向最后一个元素，这也是最后返回值是nums[left]的原因
