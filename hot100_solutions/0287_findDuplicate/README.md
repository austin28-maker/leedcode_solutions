## 解题思路

- 环形链表
    - 快慢指针
        - 快指针每次移动2步，慢指针每次移动1步
        - 快慢指针会在环的入口相遇
    - 找到环的入口，即重复的数字
        - 同速指针移动，一个从头开始，一个从相遇点开始
        - 相遇点就是环的入口，重复的数字就是环的入口

- 数组转链表的映射关系
    - 数组的下标作为链表的节点，数组的值作为链表的下一个节点

- 类比学习
    - 与0142_detectCycle题类似，都是环形链表，需要找到环的入口
    - 与0287_findDuplicate题类似，都是环形链表，需要找到重复的数字

## 注意事项

- while循环和do...while的区别
    - while循环：先判断，后执行
    - do...while循环：先执行，后判断

## 二编

- 第二遍看的时候并没有弄懂快慢指针相遇的意义
    - 让快慢指针相遇本质就是说明环形链路有环，
    - 但是此时的相遇点并不是环的入口
    - 而重复的数字就是环的入口

- 这就引出来第二个问题，
    - 如何找到重复的数字

- 难点在于理解第二个问题，即如何找到重复的数字
    - 一个点从头开始，另一个点从相遇点开始
    - 这两个点同速移动
    - 相遇点就是环的入口，为什么？a = nL - b
        - 说明从头开始到环的入口的距离等于从相遇点到环的入口的距离
        - 所以，从头开始到环的入口的距离就是重复的数字
