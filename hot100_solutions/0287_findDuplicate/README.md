## 解题思路

- 环形链表
    - 快慢指针
        - 快指针每次移动2步，慢指针每次移动1步
        - 快慢指针会在环的入口相遇
    - 找到环的入口，即重复的数字
        - 同速指针移动，一个从头开始，一个从相遇点开始
        - 相遇点就是环的入口，重复的数字就是环的入口

- 数组转链表的映射关系
    - 数组的下标作为链表的节点，数组的值作为链表的下一个节点

- 类比学习
    - 与0142_detectCycle题类似，都是环形链表，需要找到环的入口
    - 与0287_findDuplicate题类似，都是环形链表，需要找到重复的数字

## 注意事项

- while循环和do...while的区别
    - while循环：先判断，后执行
    - do...while循环：先执行，后判断
