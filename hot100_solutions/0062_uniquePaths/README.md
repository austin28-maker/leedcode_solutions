## 解题思路

- 方法一：动态规划
    - 状态定义：dp[i][j] 表示从 (i, j) 到 (m-1, n-1) 的路径数
    - 初始状态：dp[0][0] = 1
    - 状态转移方程：
    - dp[i][j] = dp[i-1][j] + dp[i][j-1]
    - 边界条件：dp[0][j] = 1, dp[i][0] = 1
    - 最终答案：dp[m-1][n-1]
- 优化一：空间复杂度优化
    - 由于状态方程只依赖上一行同列和当前行前一列的值，因此不需要保存整个矩阵。
    - 用两个一维数组 pre 和 cur 滚动地保存上一行和当前行的计算结果，
    - 每行计算完后将 cur 克隆为下一行的 pre，从而将空间需求压缩到只与列数 n 相关。

- 优化二：两个一维数组优化单个一维数组
