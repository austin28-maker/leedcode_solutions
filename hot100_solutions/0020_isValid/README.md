## 知识点

- 栈（Stack）：先进后出（LIFO，或后进先出）的数据结构。
    - 方法：addLast、removeLast、size()等
- HashMap双括号初始化，第一个括号是匿名内部类的类体，第二个括号是实例初始化块

## 解题思路

- 利用栈的先进后出性质，来判断括号是否匹配。
- 如果括号匹配，那么栈最终会为空。
- 如果括号不匹配，那么栈最终不会为空。
- 可以使用 HashMap 来存储括号的匹配关系。
    -   HashMap 中的键是左括号，值是对应的右括号。
    -   遍历字符串，如果遇到左括号，就将其入栈。
    -   如果遇到右括号，就从栈顶出栈，判断是否匹配。
    -   如果匹配，就继续遍历。
    -   如果不匹配，就返回 false。
