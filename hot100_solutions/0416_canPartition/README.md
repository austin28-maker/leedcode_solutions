## 解题思路

- 动态规划
    - 状态定义：f[j] 表示是否存在一个子集，和为 j
    - 状态转移：f[j] = f[j] || f[j - x]
    - 初始状态：f[0] = true
    - 最终答案：f[s]
- 递归

## 二编

- Python代码中 and 的优先级是高于 or 的

- 动态规划的优化思路大概可以经过以下几个阶段：
    - 子问题引出状态方程
    - 针对状态方程进行降维优化：
        - 优化前：f[i][j] = f[i - 1][j] || f[i - 1][j - x]
        - 优化后：f[j] = f[j] || f[j - x]
            - 其中f[j] 表示是否存在一个子集，和为 j
            - 滚动更新：新状态只依赖上一行 f[i][...]，更早的行再也不会用到。所以没必要保存整个表格，用同一行反复覆盖即可
            - 注意：这里需要从后往前遍历，因为 f[j] 依赖于 f[j - x]
            - 如果从前往后遍历，会覆盖 f[j - x]
            - 所以，需要从后往前遍历，确保 f[j - x] 是上一次的值

- 剪枝：注定不会有结果的分支提前砍掉，根本不去遍历，省下计算量。搜索过程像一棵树，每次选择分出一个枝；有些枝一看就知道是死路，就提前剪。
    - 作用是减少搜索空间，提高效率。
    - 本体中的一处剪枝：s2 = min(s2 + x, s)
        - s2 记录目前实际能凑出的最大和（封顶为 s）。
        - 前 i 个数总和最多 s2，比它大的 j 必然是 False，没必要扫。
