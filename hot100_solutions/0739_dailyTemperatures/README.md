## 解题思路

- 从减少遍历次数的角度对容易想到的方法进行优化
- 本题目采用了一种优化的方法，即`从右向左`遍历数组。
- 利用已经有的结果进行跳跃，避免重复遍历。

## 注意事项

- 注意一定要有跳出当前循环的操作，否则没有会一直循环下去，不能体现优化的目的了。
- 遇到0表示后面不会有更大的值，那当然当前值就应该也为0。

## 二编

- 通常是一维数组，要寻找任一个元素的右边或者左边第一个比自己大或者小的元素的位置，此时我们就要想到可以用单调栈了。
- 单调栈：栈中的元素是单调递增的，或者单调递减的。
- 更直白来说，单调栈就是用一个栈来记录我们遍历过的元素
- 单调栈中的元素表示遍历元素的下标
