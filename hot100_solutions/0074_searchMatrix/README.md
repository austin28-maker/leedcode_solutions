## 思路

- 二分查找，找中间点，判断中间点是否在目标值的左侧或右侧

## 注意事项

- 将一维数组的索引转换为二维数组的索引时，需要根据 列数n 进行转换
- 因为 idx = row × n + col，所以需要将 idx 除以 n 得到行索引 row，用 idx 对 n 取模得到列索引 col
- 取模运算和取余运算一样么？
  - 取模运算：除数 row 按照向下取整（向负无穷取整）的方式求解，再带回到 idx = row × n + col这个式子中，求最终的取模结果col，idx 表示被除数。
  - 取余运算：除数 row 按照向0取整（去掉小数点）的方式求解，再带回到 idx = row × n + col这个式子中，求最终的取余结果col，idx 表示被除数。
  - 例子：
    - 取模运算Math.floorMod(-10, 3) = 2
    - Java中取余运算用 %，所以 -10 % 3 = -1
    - Python中取模运算用 %
