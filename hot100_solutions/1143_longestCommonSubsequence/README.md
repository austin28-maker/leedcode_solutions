## 解题思路

- 动态规划
    - 状态定义：dp[i][j] 表示 s1 前 i 个字符和 s2 前 j 个字符的最长公共子序列的长度
    - 状态转移：
        - 如果 s1[i] == s2[j]，则dp[i][j] = dp[i-1][j-1] + 1
        - 如果 s1[i] != s2[j]，则dp[i][j] = max(dp[i-1][j], dp[i][j-1])

- 优化空间复杂度
    - 可以使用滚动数组优化空间复杂度，将 dp[i][j] 优化为 dp[j]

## 注意事项

- 按照我的理解，动态规划的问题最后的优化都是基于多维数组简化为一维数组
    - 这是因为动态规划的问题通常都是基于前一个状态的，所以可以将当前状态的计算结果存储在当前状态的数组中
    - 而不需要存储所有状态的计算结果
    - 二维数组的动态规划递推式可以想象为只用一个数组的新旧值，二维数组的行可以省略，主要是对列进行滚动更新
    - 即优化是针对二维数组的优化，此时已经不用太考虑原始问题了，就是对二维数组递推关系式的理解了。可以用一维数组的递推关系式来表示
