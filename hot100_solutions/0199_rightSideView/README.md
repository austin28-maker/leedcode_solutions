## 知识点

- DFS是指深度优先搜索，是一种遍历树或图的算法。
- 在树或图中，从根节点开始，每次选择一条边，遍历到的节点，直到无法继续选择边为止。

## 解题思路

- 法一：深度优先搜索（DFS）

- 法二：右子树优先遍历
    - 右优先 DFS + "每层只记第一个被访问的" = 每层最右节点 = 右视图
        - 二叉树的层数是怎么算的？
            - 从叉树的根节点开始，每次选择一条边，遍历到的节点，直到无法继续选择边为止。
            - 层数 = 节点的深度 + 1
            - 深度 = 节点到根节点的路径上的边数
            - 例如，根节点的深度为0，左子节点的深度为1，右子节点的深度为1。根节点的层数为1，左子节点的层数为2，右子节点的层数为2。

## 注意事项

- 要设置好递归函数的终止条件
- 对于无返回值的函数，里面运用了递归，也要设置好终止条件，避免无限递归。
