## 解题思路

- 贪心算法
    - 从数组的开头开始，每次选择当前可以到达的最远位置。
    - 如果在遍历过程中，当前位置大于当前最远位置，说明无法到达。
    - 如果遍历完成，说明可以到达。

## 注意事项

- 如何理解 i 和 mx 的比较关系？
    - i 是当前遍历的位置，mx 是当前能够达到的最远位置。
    - 如果 i 大于 mx，说明当前位置大于当前最远位置，无法无法到达。
    - 如果 i 小于等于 mx，说明当前位置小于等于当前最远位置，可以到达。
    - 如果遍历完成，说明可以到达。
- 所以也就引出了方法二 : 提前退出循环
    - 当 mx 大于等于数组的最后一个位置时，说明可以到达。
    - 所以，我们可以提前退出循环，返回 true。
    - 如果 mx 小于数组的最后一个位置，说明无法到达。
    - 所以，我们可以提前退出循环，返回 false。
