## 解题思路

- 动态规划
    - 状态：$f[i]$ 表示考虑前 $i$ 个任务，最大利润为 $f[i]$。
    - 状态转移：
        - 不选第 $i$ 个任务：$f[i] = f[i-1]$。
        - 选第 $i$ 个任务：$f[i] = f[i-1] + profit[i]$，其中 $j$ 是 $i$ 个任务的前一个不冲突的任务。
    - 时间复杂度：$O(n \log n)$。
- 二分查找
    - 二分查找 $j$ 时，需要找到 $jobs[j][1] \leq jobs[i][0]$ 的最大下标。
    - 时间复杂度：$O(\log n)$。
