## 解题思路

- 递归
    1. 递归边界：空节点返回[0, 0]
    2. 拆解问题：递归计算左子树的信息和右子树的信息
    3. 合并信息：计算当前节点的节点值之和 sum_ 和节点个数 size_
    4. 检查是否等于平均值：如果当前节点的节点值等于 sum_ // size_，则 ans++
    5. 返回当前节点的信息：返回当前节点值之和 sum_ 和节点个数 size_

## 注意事项

- Python
    - 整数除法 // 会自动向下取整，所以不需要额外处理
    - nonlocal 关键字用于在函数内部修改外部变量
    - 不要和Java里的 static 关键字、this指针混淆
